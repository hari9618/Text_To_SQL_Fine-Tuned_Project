    How correctness is judged
    
By execution, never text similarity. Each prediction runs
      against PostgreSQL and its result set is fingerprinted (MD5 over sorted, stringified rows).
      SELECT COUNT(*) and SELECT COUNT(customer_id) are different strings
      and both count as correct. Order is compared only where the gold query has an
      ORDER BY.

    
Guardrails: leakage-free splits by template group,
      prompt and schema fingerprints asserted at every stage, the GPU host never receives gold SQL,
      and an oracle self-test (gold SQL through the scorer) must return 100 % before any real
      number is trusted.

  


  

    Fine-tuning setup
    
QLoRA on a free Kaggle T4, one epoch, 7 h 05 m.
      Base Qwen/Qwen3-8B in 4-bit NF4; LoRA r=16, α=32 on all seven attention and MLP
      projections — 43,646,976 trainable of 4,761,498,624 (0.917 %).
      Loss is computed on the SQL only: each example is ~1,490 prompt tokens and ~46 completion
      tokens, and the prompt is ~97 % schema, identical across all 2,133 examples. Training on the
      full sequence would spend the gradient memorising a schema the model is handed anyway.
      Supervised token share: 3.01 %.
